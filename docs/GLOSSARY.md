# Glossary

| Term | Meaning |
|---|---|
| ELF | Executable and Linkable Format; verify whether and how it applies to each target file. |
| MIPS | Instruction-set family relevant to many PlayStation 2 executable-analysis workflows. Confirm the target binary's actual architecture and ABI from evidence. |
| Emotion Engine | PlayStation 2 main CPU subsystem. Hardware-specific behavior may affect portability. |
| Ghidra | Software reverse-engineering framework used for disassembly and analysis. |
| Function map | Address-indexed record of functions, candidate names, references, and confidence. |
| Checkpoint | Reproducible snapshot of repository state, evidence, tools, and remaining work. |
| Native PC implementation | Host-native code intended to reproduce game behavior without relying on a PS2 emulator as the runtime. |
