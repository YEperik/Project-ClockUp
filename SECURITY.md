# Security Policy

This repository is a research project and may eventually include project-authored tools.

## Reporting a vulnerability

Do not publish exploitable details for a security issue in a tool before maintainers have had an opportunity to assess it. Use GitHub's private vulnerability reporting feature if it is enabled for this repository. Otherwise, contact the repository maintainer through a private channel listed on the GitHub profile.

## Scope

Report issues affecting project-authored code, build scripts, automation, or repository workflows. Do not upload copyrighted game files, secrets, or personal information as part of a report.
