# Checkpoints

Store lightweight, text-based checkpoint manifests here, not disc images or large proprietary binaries.

Suggested checkpoint fields:
- Date and repository commit.
- Target file identifiers and hashes (hashes only; no game data).
- Host OS and tool versions.
- Verified milestones and evidence paths.
- Known failures, unknowns, and blockers.
- Exact next reproducible action.
