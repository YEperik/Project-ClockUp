# Ghidra Workflow

Store project-authored scripts, export settings, and setup notes here. Keep Ghidra project databases and proprietary game binaries out of Git.

Record:
- Ghidra version and extensions.
- Language/compiler specification selected and why.
- Import settings and memory map.
- Analysis options changed from defaults.
- Export procedure and validation checks.

Do not claim an architecture or ABI until it is verified against the target executable.
